# ELIX - Streaming App

A smooth streaming application with a built-in player, inspired by Yacine TV and Drama Live.

## Features

- **Movies** — Browse popular, top-rated, now playing, and upcoming movies
- **TV Shows** — Discover popular, top-rated, and currently airing shows
- **Live TV** — Watch live channels (Sports, News, Entertainment, Documentary)
- **Built-in Player** — Integrated video player with HLS support, quality controls, and fullscreen
- **Search** — Find any movie or TV show instantly
- **Responsive** — Works on mobile, tablet, and desktop with app-like navigation
- **Dark Theme** — Premium dark UI with smooth animations

## Tech Stack

- React 19 + Vite
- Tailwind CSS 4
- React Router
- HLS.js (video player)
- TMDB API (movie/show data)
- Lucide React (icons)

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
